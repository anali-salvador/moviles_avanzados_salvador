## 📖 De qué trata

Este laboratorio es sobre cómo agrupar y organizar datos en Swift usando tres tipos de colecciones:

- **Array** — colección ordenada de elementos
- **Diccionario** — pares clave-valor
- **Set** — colección de valores únicos, sin orden
